# ADR 006: Lighter Sub Circles in OKLCH

## Status

Accepted

## Context

タグの3番目と4番目のブロックから描くサブ円は、パレットの色をそのまま使わず、1つ目は少し暗く、2つ目は少し明るくしていた。調整は HSL の明度に係数0.9と1.1を掛ける方法だった。

ADR 003 でパレットの知覚明度を OKLCH で揃えたが、サブ円の調整は HSL のままだった。HSL の明度に係数を掛けると、色によって見え方が大きく違う。青（HSL 明度85%）に1.1を掛けると #E0E0FF でほぼ白になり、1.2では完全な白になる。赤では同じ係数でも淡い赤のままである。

また、メインより暗いサブ円は、メイン図形より目立ってしまう。サブ円はメインより明るくして、添え物として引かせたい。

## Decision

サブ円は2つともメイン図形より明るくする。1つ目のサブ円は OKLCH 明度0.86、2つ目は0.92にする。パレットの明度は0.80なので、どちらもメインより明るい。

明度の調整は HSL ではなく OKLCH で行う。`Color::with_oklch_lightness` を追加し、色相を保ったまま明度を目標値にする。sRGB に収まらない場合は彩度を下げて収める。青は明度0.86で彩度が0.104から0.071に、0.92で0.040に下がる。

Dots パターンの調整（ADR 002）は HSL の `change_brightness` のまま変えない。

## Alternatives

### Alternative 1: HSL の係数を1.1と1.2に変える

係数を入れ替えるだけで済み、変更が小さい。短所は、青の2つ目のサブ円が白になり、色が消えることである。選ばなかった。

### Alternative 2: メインより暗くしたまま OKLCH に移す

明度0.74と0.68などにする。サブ円がはっきり見える。短所は、サブ円がメイン図形より目立ち、どれがメインか分かりにくいことである。選ばなかった。

## Confidence Level

中程度。0.86と0.92という値は、メインと区別でき、かつ白に溶けない範囲として選んだ。目視での確認はギャラリー（`gallery.html`）で行った。

次の場合は見直す。
- 白い背景でサブ円が見えにくいとき。明度を下げる。
- パレットの明度（ADR 003）を変えたとき。サブ円の明度も合わせて動かす。

## Consequences

良い結果
- サブ円が6色すべてで同じ程度に明るく見える。
- 青のサブ円が白に溶けない。

悪い結果
- 同じタグから生成されるアイコンと下線の色が変わる。下線はサブ円の色も使う。
- 青とマゼンタのサブ円は彩度が下がり、淡くなる。

中立的な結果
- `Color` に OKLab への変換が入った。パレットの検証テストもこれを使う。
